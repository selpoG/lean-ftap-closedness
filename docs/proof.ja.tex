\begin{abstract}
本稿は有界実数値セミマルチンゲールについてのTheorem~4.2を証明する。
一般確率積分の終端市場に対するNFLVRから、Fatou閉性と弱スター閉性を導く。
選択利得ごとの補助分解、同じ凸重みの成分評価、元価格の一般積分への極限実現を順に構成し、
Leanの公開主定理が用いる仮定と証明の依存関係に対応させる。
\end{abstract}
