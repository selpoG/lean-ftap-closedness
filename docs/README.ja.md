両版とも、積分領域から Fatou 閉性・弱スター閉性までを説明し、
解析的な構成の付録と Lean 宣言の対応表を続ける。
第2節は、本文の全解析入力を七つの命題（合計20項）と二つのデータ定義として列挙する。
それらを認めれば、付録の内部補題を参照せず本文の市場の証明を追える。
各項は Lean の隔離検査で仮定化する一つの宣言に対応し、検査は日英の対応と実際の22宣言の一致も確認する。

- 付録A：分解・補償・成分ノルム。
- 付録B：共通局所化と成分級数。
- 付録C：Émery位相と同じ係数による積分実現。
- 付録D：七つの解析入力の証明。
- 付録E：数学的段階と Lean 宣言の対応。

証明を確認したい入力について、第2節の所在表から付録Dへ進み、必要な内部構成だけをA–Cで読む。
形式的な依存の分離は隔離ビルドで確認し、数学文と型の意味の一致は別途照合する。

数学本文では、有界な場合の Bichteler–Dellacherie の特徴付けと双対予測可能射影の定理を、
出典を明示した基礎結果として扱う。適用条件とノルム評価を明記し、
二つの制御測度に整合する係数の選択と元市場の成分評価は本文中で証明する。
Lean では、基礎となる分解と補償過程も構成している。

- [モジュール構成](architecture.ja.md)：各層の役割、主な証明境界、保守時の検証方法。

日本語の編集元は `proof.ja.tex` と `proof.ja/`、英語の編集元は `proof.tex` と `proof/` である。
文献一覧は `proof/` のものを共有する。本文には通常の数学的記法を使い、
Lean の宣言名は末尾の対応表にまとめる。

`task docs` または `python3 scripts/build_docs.py` で両方の PDF を生成する。
必要な TeX パッケージは [README](../README.ja.md#証明とモジュール) に記載している。
未解決の参照や組版警告が残っている場合は、PDF の更新前にビルドを失敗させる。
Lean の依存監査では、本文で参照した宣言が存在し、主定理の証明に寄与することも確認する。
