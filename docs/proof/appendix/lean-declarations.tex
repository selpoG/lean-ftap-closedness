\subsection*{The boundary between the main proof and analytic implementation}
\path{Proof/Selection/} proves lower-bound control, terminal convex compactness,
maximality-based pasting, and the uniform path limit.
\path{Proof/Components/} corresponds to Lemmas 4.7--4.10: it derives the class
bound from NFLVR, normalizes the tails, and chooses common Hilbert convex weights.
\path{Proof/OrientedSequence.lean} assembles finite Hahn improvements for the same
sequence; \path{Closedness/} proves the maximality contradiction and FV Cauchy
property corresponding to Lemma 4.11. Terminal convex compactness, maximal
elements, and the final closure arguments use \path{PositiveTail/},
\path{Trading/}, and \path{Core/}.

The main proof does not directly reference \path{Stochastic/}; it receives the seven analytic propositions of Section~\ref{sec:graph} through \path{Interface/}.

All inputs are proved in the normal build. Only the isolated copy replaces them by assumptions and rebuilds the unchanged main proof.
No theorem about selection, convexification, maximality or closedness is added as an assumption.
